# Directory rating and pricing status

See [NETWORK.md](NETWORK.md) for the current two-score model: Touchline Overall from verified portfolio metrics, and separate first-party community reviews. The previous external-review display has been replaced. No live provider is configured and no stars are fabricated.

The existing external-rating pricing configuration remains dormant and empty. All contacts currently use the base 1-credit price. Neither new Overall scores nor community reviews change prices in this release. Timed access and new price tiers remain deferred.

Names now use a visual CSS blur, as requested. This is not a security boundary: names are included in page/API responses and can be searched. Contacts and private documents retain server-side access controls. Internal source IDs and destination keys remain opaque publicly.
